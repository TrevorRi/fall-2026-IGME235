College Projects



Project 3: Lost In the Desert

  • Roles: Product Manager, UI Designer, Game Programmer
  • While working on a class project, myself and four other students collaborated to make an interactive 2D platformer based in Monogame to demonstrate for our peers. Our game was set in a desert and featured an animated fox character being forced to platform throughout a pre-loaded level that featured several enemies and obstacles to navigate around.

Project 4: Pong Rounds

  • Roles: Sole Developer
  • For a class project, I developed an interactive, two player pong game that featured simultaneous multiplayer input and an additional mechanic of giving the losing player bonuses in order to allow for a comeback. Furthermore, this project featured a novel system of constant communication between the game and other scenes allowing for dynamic updating of the scene as the players operate the game.
